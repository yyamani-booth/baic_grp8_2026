✈ Liaison

One trip plan that works for the whole group.

Everyone describes what they need in their own words: diets, walking limits, interests, budget. Liaison's AI builds a single day-by-day itinerary for the group, flags anything that might clash with someone's limits, and the plan is final only when everyone has accepted it.

Try the app demo →
  1. Tap ✨ Use example, then Continue.
  2. Add an email like dad@test.com, then continue.
  3. For each traveler: ✨ Fill example → Build my profile → Confirm profile.
  4. Generate itinerary (live AI, up to a minute), then accept or reject items.
